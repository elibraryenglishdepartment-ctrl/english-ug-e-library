# English UG Department — Digital E-Library

Ready-to-publish static website with a responsive landing page, 130 e-book catalogue entries, 30-module Grammar Hub, study tools and QR assets.

QR destination: https://elibraryenglishdepartment-ctrl.github.io/english-ug-e-library/

## Publish
1. Open/create repository `english-ug-e-library` under `elibraryenglishdepartment-ctrl`.
2. Upload all files to the repository root.
3. GitHub Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Test the published URL and scan `qr-code.png`.

## E-book links
The catalogue sends students to Project Gutenberg search pages for the selected title/author rather than redistributing book files. Project Gutenberg describes its collection as free eBooks focused on older works whose U.S. copyright has expired. Copyright status may differ by country.
